# 小说创作与独立评审方法

供创作、资料和评审子 agent 按当前已授权任务选读。记录字段见 [作品资料约定](story-records.md)。方法用于发现文本问题，不是每场必填的公式，也不以分数证明文学价值或保证获奖。仅维护或审查工具不触发本文件的小说创作流程；作者禁止试写验证时，使用技术夹具、静态检查或既有文本只读审查，不为验证规则生成小说。

## 分工与每章闭环

主 agent 沟通、主动指出问题与方案代价、计划、调度和验收；不写小说、样稿或作品资料，不用自己的意见代替独立评审。全局总编由未参与当前稿写作的真实子 agent 持续承担方向与跨章检查，可兼资料核查，须保持首读隔离。索引、决定、摘要、历史和交接由资料子 agent 写入。

文学任务同样遵守[协作流程](orchestration.md)的单书读取边界：只读本书所需材料、Skill 技术文件及当前任务获准的外部来源，绝不读取其他由本 Skill 创作的书来找风格、场景、人物、设定或结构范例；其摘要、评审、快照、压缩包和转述也不例外。不能把另一书的写法、旧反馈或约束带到本书，通用推荐免问不构成例外。已带有另一书内容的上下文不继续写作或评审，须换用仅接收本书必要资料的干净上下文。

主 agent 派前与执行子 agent 写任何实质产物前各自运行相应 gate；执行者自行读当前任务入口，未通过仅返回缺项，不先写后补账。首读者不读完整账本，接收中性任务入口后仍须独立运行 gate，只查看中性输出；具体操作及开书停点见[协作流程](orchestration.md)。

前置真实验收后才开始下一任务；产物一旦形成立即回报并登记提交，不等整章写完再补任务。提交不等于验收，已有草稿也不证明写前准备完成。发现前置仍待办、产物未登记或版本失效时，保留文本并停止依赖执行，先核对和恢复真实状态，不补造作者选择、阅读或历史验收。

**推荐不是创作决定。** 本文件中的“比较、考虑、调整、补足”先用于提出候选和代价；凡决定性创作选择，均由作者选定，范围不限于书名、视角/结构/风格、世界承重规则、人物命运/成长/关系、冲突解法及代价、转折/秘密/回收/结局。未选候选不能先进入执行大纲、有效设定或正文，不以草稿/试写变相定案。只有 agent 实际问过、作者明确选择“全部按推荐选项走且不用询问”，并有真实问题、答复及覆盖该项的范围记录，才免逐项询问；“你定”“帮我写”“AI 主导”、部分回答或全选 A 不升级为未来免问，本批免问只对该批有效，撤销或新反馈优先。已主动给定或已定的具体选择不重复问；机械执行及不改含义和已定选择的局部修错，不逐字请示。弃用名恢复的具体展示与选择要求见[协作流程](orchestration.md) §3。

每章，包括试写、导入后改写、旧章重写，都由创作子 agent 起草，再由**未参与该稿撰写的另一个实际子 agent**完成文学与连贯性评审；可以顺序调用。评审者不直接修改被评正文。实质修订使相关旧结论过期，须复核变化及关联影响。不能用主 agent 扮演不同身份替代独立评审；环境没有真实子 agent 能力时说明限制、保留现场，不代写代评。

写前按故事时点查证并核对决定依据；需要新的决定性选择时先提交选项，不能起草定案后再求追认。依据已定选择起草，评审、返工和必要复核完成并满足作者参与约定后，采用正文，资料子 agent 增量更新所有受影响资料。每类均做变化筛查，无变化集中注明，未知保持未知。严重冲突未解决可留草稿，不宣称完整通过。主 agent 验证文件、版本、证据、处理结果和同步情况，缺项交回子 agent 补做。

## 构思验证：先找持续产生选择的矛盾

先依据作者具体选择或覆盖该项的有效免问记录确定本轮需要的读者与体验方向：紧凑追读、关系情感、语言与观察、类型解谜等可组合，不以文学奖、慢写或商业套路预设高低。关键方向或资料模式未选且无有效免问记录时，先提出少量选项、推荐及代价并等待，不用下列构思方法先做实质定案。以已定选择说明人物的独特处境、持续矛盾、退出代价、可争论的主题，以及读者除了等谜底还会关心什么。新方向只作为选项比较，说明吸引力、篇幅潜力与主要风险，不写成执行大纲；契约范围与开书资料模式见[协作流程](orchestration.md) §3。

对作者已选的关键走向用简梗概推演：每次选择怎样改变条件，下一次是否面临不同的损失与责任？未选走向可作为明确标注的候选比较，不写入执行大纲。若只靠增加误会、延迟答案和重复失败延长故事，提出改变冲突、缩短篇幅或暂存的选择与代价，让作者选。检查人物与关系有没有变化空间，世界限制是否真的生效。

按已选或有效免问记录覆盖的资料建设模式完成必要准备，进入已选定的试写范围、所需决定性变量也已选后，以少量代表场景或一章检验声音、人物张力和阅读感受，不以档案规模替代验证。“只试写”只规定任务范围，不能替代其中视角、风格、人物走向等未定选择；只整理资料时不触发试写，缺少答复时不把小样当作默认探索。留下依据、薄弱点、下次实验及继续或调整的理由。探索性作品可有意承担不确定性；一次试写不能证明长篇成功。

## 场景：让读者经历变化

写前简记视角、故事时间、地点、眼前诉求、阻力、可选行动与结束后的变化，说明前后因果或情感连接，以及详写、略写、跳过哪些过程、为什么。预算服从本书约定与场景作用，不凑统一字数。按用途选用：

- 行动场景：人物争取什么，限制迫使他怎样选择，失去或得到什么？不要跳过关键行动过程只报告结果。
- 对白场景：双方各想得到、回避或隐瞒什么？让措辞、停顿、物件和行动改变谈话局面。只有背景交换时，压缩说明，或让信息影响当下决定；不机械补争吵。
- 安静与观察场景：注意力、认识、关系、情绪或意象发生什么细微变化？可以没有外部冲突，保留其审美作用与留白。

让空间和感官有作用：门的位置限制退路，职业习惯改变观察方式，身体不适打断一句话。核对人物能否感知、理解信息，动作与道具在空间中能否连续，时间跳跃与代词换指是否可辨；让读者回读才能分清谁在做什么，先修叙述导航，不能称为留白。删去场景会失去什么？结尾可以是理解、余波或停顿，不必每次反转、悬念或两难。

## 人物、成长与独立性

把目标、需要、恐惧、羞耻、价值排序和自我矛盾落实为行动证据。关键选择用“欲望—阻力—选择—代价—后果”追问：他保护了什么，又牺牲了什么？比较公开与私下、强势与受压时的表现，避免用新增形容词补救失真的行动。

有限、被迫、沉默和停滞都可以成立，不强迫人物成为主动英雄；但读者应能辨认他此刻想保住什么、拒绝什么、为何顺从。身体反应、物件与意象不自动等于人物诉求。“不解释”约束表达方式，不能升级为“不许人物有愿望、判断或改变”；克制失去可读性时比较补行动、调整距离或缩减限制，不能只加一串生理反应。

成长按“起点—压力—选择—代价—反思—行为变化”积累，计划与实际分开。一次勇敢不等于从此无畏；下一次更高代价的选择才检验变化是否站稳。倒退、停滞、堕落和坚守均可作为候选，由作者选定具体走向。改稿新增行为后，反查未来大纲的“第一次”是否已发生：若需把后续节点改成目的、风险或支配权升级，先提出方案由作者选；不能继续声称首次，也不为守大纲删除有效新稿。转变突兀时比较补经历、延后或缩小变化的代价，不自行确定成长路径。

重要配角与反派要能回答：没有主角时他在做什么，自己的责任、利益、日常关系和计划是什么，为什么认为自己有理？关键决策分别从各人的可知信息、可选行动、可承受代价推演，不能让对手突然变笨。候选动机不自动成为事实。

人物不肯按大纲行动时，比较调整事件、补足动机和改变成长计划的代价；新的决定性取舍均交作者选，不仅限于涉及原有核心约定时。区别人物声音应依靠观察、职业判断、幽默、回避和价值排序，不只靠口头禅。关系变化双向分别检查：甲愿意合作，不意味着乙已信任；背叛与和解要有双方不同的理解和后果，具体关系走向由作者选定。

## 主题、因果与多故事线

把主题写成能被不同人物争论的问题。例如“保护亲人是否可以牺牲无辜者”，让各人作出有代价的不同回答，再由后果和结局回应开篇。不要让人物轮流宣讲同一标准答案。意象重现时，检查含义是否随处境变化，而非以重复次数充当深度。

主题、大纲与意象是待文本检验的方案，不能让人物只承担作者结论。无名、反高潮或特殊终章只在本书明确选择后成立，不推广为通则；改编须区分原素材、衍生解读与本书新设定，无法读取原件时不声称完成忠实度核对。

串联事件时写出“因为……所以人物选择……结果……”。分别核对时间先后、因果和必要条件；相邻不等于因果。重大转折须能回溯动机、条件或线索。偶然可以制造困境，解决核心困境须防止无依据巧合。

主线、成长线与关系线在关键事件中改变彼此的条件。每条支线至少改变选择、呈现主题另一面或留下后果；否则考虑合并、删减或改写。阶段回看长期失踪、原地绕圈、过早耗尽的线，明确继续、搁置及复查点、收束或放弃；已经向读者许下的承诺仍需处理。

## 情感积累、曲线与节奏

高潮前查“读者为什么在乎”：此前看见的具体生活、珍惜之物、共同经历和愿望是否建立期待？重大失去缺少力量时，优先补足关心与期待、调整兑现方式，而非增加灾难或情绪词。胜利、死亡、背叛、和解之后，跟踪身体、日常、关系、信念和社会处境的持续余波。

分场景、章、阶段、全书观察冲突压力、风险与代价、悬念、情绪感受、希望与挫败、信息揭示。计划目标与成稿判断分列，每项给文本依据；未分析就是未知，不自动画平滑曲线，不合成文学总分。

节拍是动作、发现、选择、转折、停顿的安排；节奏是实际阅读的快慢、密度和呼吸。通过场景长度、时间展开与压缩、行动与反思、对白与描写、信息密度、视角切换和章间衔接调整。快场不能省因果，慢场要有作用，紧张后允许喘息。

详写留给会改变选择、认识、关系或体验的过程；重复劳作、转场和已建立的仪式可概述、合并或省略。段段可感不等于全章有效：连读检查相同句法、情绪、动作和意象是否停在同一层，必要时删整段而非只换同义词。短句不天然快，长句不天然慢；不以对白/描写占比或每章字数证明节奏。

连续高压使人麻木，可留余波让代价落地；重复胜利失去分量，可改变胜利的代价或目标；反转无铺垫，回查可见线索与人物动机。每项调整说明想改变的阅读体验，不能为了曲线漂亮硬造波折。

**阅读动力与钩子**：写前说明读者此时最关心的问题、人物或愿望，本章推进/兑现什么、留下什么值得承接。钩子可来自关系、选择、后果、信息差或具体目标，不必都是谜团；章尾余韵也可成立。不能只添谜不兑现、反复打断将发生的事、用含糊代词假造秘密；有意留白应与作品约定一致，不把答应会给的答案事后改成“永不解释”。总编结合前文检查承诺是否仍活跃，避免每章一个硬悬崖或连续压抑无差别。

## 世界、生活与真实感

让交通耗时、交易、职业操作、礼仪、制度、阶层和生活物件限制行动，不以百科说明代替生活。能力、技术或超自然规则提前呈现条件、边界和代价；救场例外需要已有依据，且后续同样适用。

区分世界客观规则、传说、宣传和角色理解。战争、改革或灾难要改变具体人的日常及选择。现实资料记录实际查阅来源、支持范围和待核实项，未查证不能声称核实；虚构与现实依据分别标明。

优先核实承重规则：人物为何不能离开、为何相信某条退路、惩罚怎样发生、能力怎样解围。一般惯例或间接资料不自动支持特定年代、地点、身份的结论；查不到先保留未知，提出调整情节条件或虚构规则的选项、推荐及代价，由作者选定或按有效免问范围执行。泛泛允许虚构不等于选定具体承重规则，不靠堆来源链接把推论写成史实。关键规则须先于其决定性后果建立到足够可理解的程度。

关键场景只有泛泛的职业、制度或生活描写时，先指出影响行动的具体素材缺口，再有针对性地查阅来源或使用作者提供的经验。由创作子 agent 将所得材料落实为行动过程、选择条件或代价的变化，留下少量修订前后对照及采用依据；来源支持范围与未知项沿用资料规范。检查材料是否改变了事件怎样发生，不为展示知识堆入无关说明。

## 语言与作品声音

按作品语言约定写作：人称与视角、叙述距离、词语气质、句子节奏、感官侧重、对白差异与标点。中文对白默认用中文双引号“……”、引号内再引用用单引号‘……’；作者、繁体排版或平台另有规范时依其有效约定，不把一种形式说成普遍错误。核对说话内容、引用层级、破折号与省略号的语境，不全局盲替换。机械检查只定位异常与明确约定违例，不评文学好坏。

用少量本书采用片段和作者反馈校准声音，区分作者亲笔、采用的 AI 试写和未采用实验。没有本书样本时先了解偏好或在已选范围内试写，不读取其他由本 Skill 创作的书来填补样本；外部参考须符合单书边界与真实授权。偏好须有来源与适用范围；只选某章方案不能推广全书。稠密、克制、短句等风格标签不能自行推导成慢节奏、一段一行、不解释、触觉优先或禁止内心等硬禁令；若建议这些做法，记录为可比较提案及其代价，由作者选定或按覆盖该项的有效免问记录执行。不能把 agent 自拟的风格规则当成作者禁令，也不能用这些提案或“符合风格”抹去困惑、跳读、人物诉求不清等真实首读反馈。发现阅读目标、节奏或表达偏移时，展示实际差异并在必要范围重新校准，已定且无变化的选择不每章重复问。

开书或重大风格调整进入已选定的试写范围时，创作子 agent 对同一关键场景试写两个实质不同的叙述方案；叙述距离、注意力、时间压缩与密度等决定性比较变量先由作者选择，或核验覆盖它们的有效免问记录，已有视角约定时在其边界内实验。保持可比较的已选情节与信息，避免一个方案靠额外情节占优。匿名首读后再核对意图，最终方案由作者选择或按覆盖该项的有效免问记录执行，保存适用范围、代表片段与理由，在不同场景检验延续性。无需逐章重复，不把更整齐、修辞更多当作更好。

修订先判断是否需要现场化，不把一切抽象概述改成更长的动作与感官；有效概述与留白可以保留。检查重复解释、套话、虚浮比喻、对白同声和机械句式，同时保留有作用的粗粝、歧义、方言、停顿与不规则节奏。每个改动都问是否更准确、是否抹掉辨识度；重大风格变化记录理由与生效范围。

## 独立阅读、评审与返工

每章采用两阶段阅读：首轮派未参与写作的评审子 agent，使用空白或隔离上下文，不继承创作讨论；只提供明确版本的正文、必要前文、阅读顺序及中性背景。必要前文应足以理解承接与已形成的阅读承诺；缺失时记录判断限制。隐去意图、未来秘密与预期答案。先保存自由反馈：何处在乎、困惑或想跳读，怎样理解人物诉求，最想继续追什么，章尾承接是否有效；附实际输入清单与哈希。封存后再提供意图与资料，核查连贯性和效果落差，不能事后改写首读或仅以“有意设计”否定体验。版本证据见[文件协议](file-protocol.md)。

宿主无法隔离本书创作讨论，或评审者已接触本书创作讨论时，如实标为普通评审并写明信息暴露与阅读范围，不声称完成盲读；仍由另一实际子 agent 完成必需评审，不因此阻止已授权创作。此降级只针对本书意图隔离；带有另一书内容时仍须停止并更换干净上下文。不同任务身份本身不证明判断独立。

每项重要意见包含原文位置与片段、问题机制、读者影响、性质、可选改法及代价。分开处理：

- **事实或约定硬冲突**：证据支持的因果/连贯性错误、作者明确硬约定违例、采用稿缺必需独立复核，须修复后采用。作者可以修订约定，但不能用一句“有意保留”声称事实矛盾已消失。
- **主要阅读问题**：人物长期诉求不可辨、成组重复、成长节点失效、主要承诺不推进等，须实际处理或依据作者选择有理由保留，记录影响与复查点；不能因非事实错误或标为 soft 就直接放行。修复涉及新的决定性创作取舍时，先交作者选或核验有效免问记录，不能仅因笼统“已授权修稿”自行确定；机械修错不逐字请示，不把所有文学建议自动升为 hard。
- **可选审美建议**：局部修辞、节奏与偏好分歧可保留，不阻断采用；已处理或按授权保留且输入与影响未变，不因换评审重复返工。

性质与脚本字段映射按[文件协议](file-protocol.md)执行，不自造 schema。角色行为按当时知情、利益与可选行动判断，不能拿全知答案苛责；内部解释不等于问题已经解决，文学效果不由分数或多数票裁定。

返工先处理影响大量后文的问题，再处理场景与语言；每项记录采用、部分采用或保留及其代价。创作子 agent 修改，未参与当前稿写作的评审对实际采用版本复核。影响清晰时可按已完整阅读的基稿、变化映射和关联范围增量复核；基稿未读或影响难界定时扩大阅读。记录实际方法与版本链，主 agent 看 diff 不替代复核，旧“通过”不能只换哈希沿用。两轮针对性返工仍受阻时保留草稿与有限方案交作者，不无限加审。资料子 agent 同步实际变化及撤销的旧约束。

总编每章简查方向和实际变化，试写后、阶段结束、重大转折/修订，以及连续枯燥反馈、承诺停滞、节点重复或风格漂移时，连读相关成组章节；不只看摘要，也不按固定章数凑审。检查阅读动力、松紧、承诺兑现、支线、成长、主题与声音。全书定稿须有当前全稿版本与阅读顺序的整体阅读，不能拼接逐章通过或局部抽查替代；可分批通读，记录覆盖，未读完不宣称完成。整体报告以文本说明成就与最大不足，重点检查后半部重复、人物变化与结尾回应。

依整体意见进行必要的结构修订，若不需要则记录依据；由评审子 agent 复核新稿及全书关联影响。重大问题须实际处理，或依据作者决定或既有授权有意保留并说明理由，再报告定稿；事实硬冲突仍按原门槛处理。保留审美分歧，不要求所有评审无异议或以投票决定。版本、复核与采用仍走[文件协议](file-protocol.md)及逐章闭环。

外部读者反馈有价值，但缺席不阻止已授权工作；如实标明待外部验证，不伪造反馈，也不自动联系他人。文件可靠性与文学效果分开报告，后者用实际文本、修订对照和阅读理由支撑，不用自评分代替判断。
