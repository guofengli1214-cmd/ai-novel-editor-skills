# 小说创作与独立评审方法

供创作、资料和评审子 agent 按当前任务选读。记录字段见 [作品资料约定](story-records.md)。方法用于发现文本问题，不是每场必填的公式，也不以分数证明文学价值或保证获奖。

## 分工与每章闭环

主 agent 只沟通、计划、调度、验证产物和组织返工；不写小说、样稿、改写段落，不编写或直接修改作品资料，不出具文学评审结论。作品内的索引、决定、摘要、历史和交接也由资料子 agent 写入。

每章，包括试写、导入后改写、旧章重写，都由创作子 agent 起草，再由**未参与该稿撰写的另一个实际子 agent**完成文学与连贯性评审；可以顺序调用。评审者不直接修改被评正文。实质修订使相关旧结论过期，须复核变化及关联影响。不能用主 agent 扮演不同身份替代独立评审；环境没有真实子 agent 能力时说明限制、保留现场，不代写代评。

写前按故事时点查证；起草时只提交候选变化；评审、返工和必要复核完成并满足作者参与约定后，采用正文，资料子 agent 增量更新所有受影响资料。每类均做变化筛查，无变化集中注明，未知保持未知。严重冲突未解决可留草稿，不宣称完整通过。主 agent 验证文件、版本、证据、处理结果和同步情况，缺项交回子 agent 补做。

## 构思验证：先找持续产生选择的矛盾

用一小段说明人物的独特处境、核心矛盾、不能轻易退出的原因、可争论的主题问题，以及读者除了等谜底还会关心什么。比较少量真正不同的方向，说明吸引力、篇幅潜力与主要风险。

用简梗概推演几个关键选择：每次选择怎样改变条件，下一次是否面临不同的损失与责任？若只靠增加误会、延迟答案和重复失败延长故事，考虑改变冲突、缩短篇幅或暂存。检查人物与关系有没有变化空间，世界限制是否真的生效。

以一至三个代表场景或一章试写检验声音、人物张力和阅读感受，不先搭建庞大档案。留下实际依据、薄弱点、下一次实验及继续或调整的理由。探索性作品可有意承担不确定性；一次试写不能证明长篇成功。

## 场景：让读者经历变化

写前简记视角、故事时间、地点、眼前诉求、阻力、潜台词、行动及结束后的变化，并说明与前后场景的因果或情感连接。按用途选用：

- 行动场景：人物争取什么，限制迫使他怎样选择，失去或得到什么？不要跳过关键行动过程只报告结果。
- 对白场景：双方各想得到、回避或隐瞒什么？让措辞、停顿、物件和行动改变谈话局面。只有背景交换时，压缩说明，或让信息影响当下决定；不机械补争吵。
- 安静与观察场景：注意力、认识、关系、情绪或意象发生什么细微变化？可以没有外部冲突，保留其审美作用与留白。

让空间和感官有作用：门的位置限制退路，职业习惯改变观察方式，身体不适打断一句话。核对视角人物能否感知、理解这些信息，叙述距离是否适合现场。删去场景会失去什么？结尾可以是理解、余波或停顿，不必每次反转、悬念或两难。

## 人物、成长与独立性

把目标、需要、恐惧、羞耻、价值排序和自我矛盾落实为行动证据。关键选择用“欲望—阻力—选择—代价—后果”追问：他保护了什么，又牺牲了什么？比较公开与私下、强势与受压时的表现，避免用新增形容词补救失真的行动。

成长按“起点—压力—选择—代价—反思—行为变化”积累，计划与实际分开。一次勇敢不等于从此无畏；下一次更高代价的选择才检验变化是否站稳。允许倒退、停滞、堕落和坚守。转变突兀时，比较补经历、延后转折或缩小变化，而非仅在人物卡上宣布成熟。

重要配角与反派要能回答：没有主角时他在做什么，自己的责任、利益、日常关系和计划是什么，为什么认为自己有理？关键决策分别从各人的可知信息、可选行动、可承受代价推演，不能让对手突然变笨。候选动机不自动成为事实。

人物不肯按大纲行动时，比较调整事件、补足动机和改变成长计划的代价；涉及作者核心约定则提出具体选择。区别人物声音应依靠观察、职业判断、幽默、回避和价值排序，不只靠口头禅。关系变化双向分别检查：甲愿意合作，不意味着乙已信任；背叛与和解要有双方不同的理解和后果。

## 主题、因果与多故事线

把主题写成能被不同人物争论的问题。例如“保护亲人是否可以牺牲无辜者”，让各人作出有代价的不同回答，再由后果和结局回应开篇。不要让人物轮流宣讲同一标准答案。意象重现时，检查含义是否随处境变化，而非以重复次数充当深度。

串联事件时写出“因为……所以人物选择……结果……”。分别核对时间先后、因果和必要条件；相邻不等于因果。重大转折须能回溯动机、条件或线索。偶然可以制造困境，解决核心困境须防止无依据巧合。

主线、成长线与关系线在关键事件中改变彼此的条件。每条支线至少改变选择、呈现主题另一面或留下后果；否则考虑合并、删减或改写。阶段回看长期失踪、原地绕圈、过早耗尽的线，明确继续、搁置及复查点、收束或放弃；已经向读者许下的承诺仍需处理。

## 情感积累、曲线与节奏

高潮前查“读者为什么在乎”：此前看见的具体生活、珍惜之物、共同经历和愿望是否建立期待？重大失去缺少力量时，优先补足关心与期待、调整兑现方式，而非增加灾难或情绪词。胜利、死亡、背叛、和解之后，跟踪身体、日常、关系、信念和社会处境的持续余波。

分场景、章、阶段、全书观察冲突压力、风险与代价、悬念、情绪感受、希望与挫败、信息揭示。计划目标与成稿判断分列，每项给文本依据；未分析就是未知，不自动画平滑曲线，不合成文学总分。

节拍是动作、发现、选择、转折、停顿的安排；节奏是实际阅读的快慢、密度和呼吸。通过场景长度、时间展开与压缩、行动与反思、对白与描写、信息密度、视角切换和章间衔接调整。快场不能省因果，慢场要有作用，紧张后允许喘息。

连续高压使人麻木，可留余波让代价落地；重复胜利失去分量，可改变胜利的代价或目标；反转无铺垫，回查可见线索与人物动机。每项调整说明想改变的阅读体验，不能为了曲线漂亮硬造波折。

## 世界、生活与真实感

让交通耗时、交易、职业操作、礼仪、制度、阶层和生活物件限制行动，不以百科说明代替生活。能力、技术或超自然规则提前呈现条件、边界和代价；救场例外需要已有依据，且后续同样适用。

区分世界客观规则、传说、宣传和角色理解。战争、改革或灾难要改变具体人的日常及选择。现实资料记录实际查阅来源、支持范围和待核实项，未查证不能声称核实；虚构与现实依据分别标明。

关键场景只有泛泛的职业、制度或生活描写时，先指出影响行动的具体素材缺口，再有针对性地查阅来源或使用作者提供的经验。由创作子 agent 将所得材料落实为行动过程、选择条件或代价的变化，留下少量修订前后对照及采用依据；来源支持范围与未知项沿用资料规范。检查材料是否改变了事件怎样发生，不为展示知识堆入无关说明。

## 语言与作品声音

按作品的语言约定写作：人称与视角、叙述距离、词语气质、句子节奏、感官侧重、对白差异。用少量采用片段和作者反馈作对照，区分作者亲笔、AI 试写后采用的作品声音和未采用实验。

开书或重大风格调整时，创作子 agent 对同一关键场景试写两个实质不同的叙述方案，可从视角、叙述距离、注意力分配或时间处理入手；已有视角约定时在其边界内实验，不强行改换视角。资料子 agent 用中性编号匿名交评审者分别先读、留反馈，再比较阅读效果，不透露预选方案或推荐理由。由作者选择，或依既有授权选定，保存采用片段与理由，并在后续新场景检验这种声音能否延续。无需每章重复对照，也不把更整齐、修辞更多当作更好。

修订时把抽象判断落到可感知的动作与细节；检查重复解释、套话、虚浮比喻、对白同声和机械句式，同时保留有作用的粗粝、歧义、方言、停顿和不规则节奏。每个改动都问：更准确了吗，是否抹掉作品的辨识度？新 agent 以实际新稿对照代表片段，发现偏移先指出具体差异。重大风格变化记录理由与生效范围。

## 独立阅读、评审与返工

每章采用两阶段阅读：首轮派未参与写作的评审子 agent，使用空白或隔离上下文，不继承创作讨论；只提供明确版本的正文、必要前文、阅读顺序及中性题材背景，隐去创作意图、未揭示秘密、预期好评和作者想要的结论。评审者先将自由反馈落盘，记录被打动、困惑、想跳过的位置，人物动机理解、期待和记住的细节，并保存实际输入清单、正文及必要前文的哈希。主 agent 验证首轮产物存在后，再提供创作意图、秘密及有关资料，完成连贯性和意图落差核查；保留首轮原始反馈，勿事后改写成符合意图的感受。版本与证据保存遵循[文件协议](file-protocol.md)。

宿主无法隔离上下文，或评审者已接触创作讨论时，如实标为普通评审并写明信息暴露与阅读范围，不声称完成盲读；仍由另一实际子 agent 完成必需评审，不因此阻止已授权创作。不同任务身份本身不证明判断独立。

每项重要意见包含原文位置与片段、问题机制、读者影响、严重程度、可选改法及其代价。区分确定矛盾、需要作者选择、可选改善和有意保留。角色行为评审按当时知识与利益判断，不能拿全知答案苛责角色。

返工顺序通常为主题与结构、人物与关系、因果与世界、场景与节奏、语言细节；先修将影响大量后文的问题。创作子 agent 修改，评审子 agent 对照新旧稿复核问题及关联范围，资料子 agent 同步实际变化。保留未采用意见与理由，不以多数票抹平审美分歧。多轮未解、关键事实缺失或方向待定时，留下具体待办和草稿，向作者说明，不无限循环或虚报通过。

试写后、阶段结束、重大修订和完稿时增加整体独立阅读，检查承诺兑现、支线、成长、主题和全书声音。全书定稿须有对应当前全稿版本和阅读顺序的整体阅读，不能以逐章通过、摘要或局部抽查替代；可分批通读，记录实际覆盖范围，未读完不宣称完成全书审读。整体报告用文本说明最突出的成就与最大不足，重点检查后半部是否重复、人物变化是否站得住、结尾如何兑现或重新解释前文。

依整体意见进行必要的结构修订，若不需要则记录依据；由评审子 agent 复核新稿及全书关联影响。重大问题须实际处理，或依据作者决定或既有授权有意保留并说明理由，再报告定稿；事实硬冲突仍按原门槛处理。保留审美分歧，不要求所有评审无异议或以投票决定。版本、复核与采用仍走[文件协议](file-protocol.md)及逐章闭环。

外部读者反馈有价值，但缺席不阻止已授权工作；如实标明待外部验证，不伪造反馈，也不自动联系他人。文件可靠性与文学效果分开报告，后者用实际文本、修订对照和阅读理由支撑，不用自评分代替判断。
