# 小说创作工作室

按作者选择的题材、读者与阅读体验辅助长篇创作；文学向、类型向、连载或实验写作不设统一审美答案。不用自评分、档案数量或流程通过代替阅读证据。不用于一般文案润色。

## 分工与执行边界

主 agent 负责沟通、主动提示问题与方案代价、规划、派工、只读检查和验收，不只报告流程通过。正文、试写、改写和场景计划由真实创作子 agent 编写；作品资料由相应子 agent 维护。全局总编由未参与当前稿写作的真实子 agent 承担，持续检查方向与跨章效果；当前稿另须独立阅读与复核。总编职责可与资料核查合并承接，不污染首读。不得模拟角色、自评或由主 agent 代写、代评缺失产物。

宿主须提供真实派工、传递资料和取回结果的能力；支持顺序派工即可。缺此能力时保留现场并说明迁移条件，不代写代评，不自行改宿主配置。文件里的身份与授权只是申报，主 agent 对照实际宿主记录、作者原话和版本核验。已结束的子任务不能续聊时新派真实 agent，传递产物与哈希，如实记录身份和阅读历史。

决定性创作选择由作者选定，范围不限于书名、视角/结构/风格、世界承重规则、人物命运/成长/关系、冲突解法与代价、转折/秘密/回收/结局。推荐不等于决定，候选不得先写入执行大纲或正文变相定案。唯一免逐项询问条件：agent 确实问过，作者明确选择“全部按推荐选项走且不用询问”，并记录实际问题、答复及覆盖当前选择的范围；“你定”“帮我写”“AI 主导”、部分回答或全选 A 均不能推成未来免问，本批免问只对该批有效。新反馈或撤销优先。恢复弃用书名须在实际选项中点名并提示曾弃用，可由作者单选或对该批明确全选免问；未指向该名称的泛授权不能暗中复用。作者已主动给定的具体选择不重复问。细则见[协作流程](references/orchestration.md) §3。

写书实行单作品隔离：只在作者明确的当前作品根目录内定位和读取作品材料，不扫描作品库，不读取其他由本 Skill 创作的书的正文、设定、大纲、摘要、评审、快照或压缩包，也不调用它们的记忆、检索结果或已污染的 agent 上下文。技术规则可读，外部非本 Skill 作品的参考另须作者指定；不能把其他 Skill 作品复制入当前目录来绕过隔离，“全部推荐免问”也不放宽此禁令。派工明确当前书根和允许读取清单；已接触其他书内容的上下文不得继续本书构思或写作，须换隔离的新上下文，具体见协作流程 §1–2。

## 每次执行的最小入口

1. 已有作品先确认唯一当前书的绝对路径，只在该书根内读顶层 `索引.md`、`创作约定/写作进度与接续说明.md`、`创作约定/作品状态.json` 和当前任务账本入口；不为找书遍历父目录。旧当前未关闭阶段继续实质工作前，按任务管理显式开启 `execution_gate_version: 1`，不改历史完成项。先处理 `pending_operations`、失效证据、手改及产物与任务脱节；越序产物保留原样，只恢复记录和补做真实缺项，不先继续创作。新书先只读理解已给的本项目材料，不为恢复现场而先建书。
2. 恢复作者契约、语言标准、作者已定选择和当前阶段。新书缺少本轮所需的阅读/叙述方向、先建资料/边写边补/混合的资料模式或其他决定性选择，且无覆盖该项的有效免问记录时，首次回复复述已知、补问少量关键缺项后等待答复。有限探索仅指只读理解与在回复中列选项，不边问边补设定、大纲或试写。已定具体选择不重复问，不要求一次定完未来全部选择；整理或试写的任务指令只许可该任务，不豁免其中未定的决定性选择，部分回答不视为全部答完。
3. 按下表读取所需小节，提供当前书根、精确允许读取文件、章节、写入范围与验收条件。主 agent 派前运行 `taskctl.py gate --book BOOK --stage ID --before KIND`，由资料子 agent 登记本任务 `doing` 后才开始实质工作；执行子 agent 写前独立重跑 gate，未过只返回缺项，不先写后补账。首读不读账本，自行运行带 `--neutral` 的 gate，具体见协作流程；无需每章通读所有参考文档，也不把未来秘密交给首读者。
4. 准备（含总编简查、详略取舍）→ 草稿 → 独立首读及资料核查/总编检查 → 必要修订与当前稿独立复核 → 正式采用及资料同步 → 主 agent 验收。主要阅读问题须处理或按授权有理由保留，审美建议不强制通过；不能只因无事实矛盾而采用。每一步保留真实产物、版本与未完项，检查证据格式见任务管理及文件协议。

## 完成与接续

作品顶层按连续章号保存当前正式正文，资料在有索引的子目录；工具生成的历史快照和采用日志只读保留。重要事实区分正文、作者要求、计划、推测和角色误信，带对象标识、故事时点、出处及核对版本。摘要用于定位，不代替原文。逐章筛查所有资料类别，只详细更新实际变化或构成约束的内容。

首读先只给正文、足以理解承接关系的必要前文与中性背景，保存原始反馈后才补意图和秘密；无法隔离时注明普通评审及限制。修订复核须对应实际采用稿，可由独立 agent 按已读基稿和变化范围增量复核；主 agent 看 diff 不替代它。开书或重大风格调整在授权内做同场景对照试写，选择范围不可擅自推广。仅维护或审查 Skill 不触发小说创作；作者禁止试写验证时只用技术夹具、静态审查或既有文本只读检查，并如实说明文学效果尚未验证。

每个产物返回就立即登记 `submitted`、路径与哈希并核对任务游标，主 agent 核验文件、哈希、评审与授权，再派资料子 agent 记录验收为 `done`；未验收不得派依赖它的下一项，不等整章或多轮结束后补账。草稿存在不代表草稿已验收，更不能据此补勾前置任务；发现脱节先停创作、如实恢复。版本变化按影响重新打开任务。采用用 `chapterctl adopt`，资料与索引同步后用 `finish`；阶段关闭用 `taskctl close` 并留下下一阶段或本轮终点。全书定稿另须完整当前稿的整体阅读、修订及复核证据和 `bookctl check`；章节完成不替代全书定稿，工作稿可按既有授权导出。

已定选择的机械执行、资料同步及不改变选择的修错继续，细微措辞不逐字请示；新的决定性选择先给少量方案、推荐与代价，由作者选定或按覆盖它的有效免问记录执行。两轮针对性返工仍受阻则保留现场与分歧，不无限加审。同步须撤销过期约束、反查未来计划与成长节点，推测不写成事实；接续与账本对应实际产物，不能只换哈希恢复通过。换会话或工具依靠普通文件与真实来源，不依赖旧子任务存活。
